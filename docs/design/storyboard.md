# 시연 영상 · 숏폼 스토리보드 — 충전쉼표 (Plug & Rest)  v0.1 / 2026-11-03

기준: docs/pm/10-prd.md §4·§7. 앱명·팀명은 확정 시 치환 (`충전쉼표`, `{팀명}`).

## 공통 규칙
- **개인정보 금지**: 실명·얼굴·목소리·이메일·macOS 사용자명(`/Users/...` 경로, 메뉴바 계정)·Android Studio 창 노출 금지. 녹화 영역은 에뮬레이터 + Virtual Console 창만.
- **내레이션**: 개발자 육성 대신 합성 음성(macOS `say -v Yuna` 또는 Runway TTS). 앱 TTS 소리와 겹치는 구간은 내레이션 생략.
- 앱 TTS 음성은 **원본 오디오 그대로** 살림 (차량 기능이 실제로 동작한다는 증거).
- 자막: 하단 중앙, 흰 글자 + 반투명 검정 박스, 한 줄 18자 이내. 강조색 = 아이콘 민트 `#43E0A0`, 앰버 `#FFC75A`.
- Console에서 값이 바뀌는 순간은 해당 영역에 민트 테두리 박스 하이라이트(편집에서 추가).

## 앱 TTS 확정 문구 (PM 확정, PRD v0.5)
| 시점 | 문구 |
|---|---|
| 휴식 시작 | 휴식 모드를 시작합니다. 목표 80%에 도달하면 깨워 드릴게요. |
| 목표 도달 | 목표 80%에 도달했습니다. 10초 후 시트를 원래대로 되돌립니다. |
| 재정차 제안 | 시트를 원래대로 되돌릴까요?  (영상·시연 제외, PT Q&A용) |
"충전 완료" 표현은 자막·내레이션·화면 어디에도 쓰지 않음.

## 녹화 방법 메모 (macOS)

### 1. 동시 녹화 — OBS Studio 권장
기본 화면 녹화(⌘⇧5, QuickTime)는 **시스템 오디오가 녹음되지 않아** 앱 TTS가 빠짐. OBS는 macOS 13+에서 앱 오디오를 직접 캡처함.
1. `brew install --cask obs`
2. 캔버스/출력 1920×1080, 30fps.
3. 소스 추가: **macOS 화면 캡처 → 방식 "창"** ×2 (에뮬레이터 창, Virtual Console 창). 위 `SPLIT` 비율로 배치. 에뮬레이터 창 제목에 사용자명이 보이면 크롭으로 제목줄 제거.
4. 소스 추가: **macOS 오디오 캡처 → 애플리케이션 = qemu-system-aarch64**(에뮬레이터 프로세스). 마이크는 끔.
5. 녹화 형식 mkv(중단돼도 복구 가능) → 끝나고 `파일 > 녹화 리먹스`로 mp4.
6. 에뮬레이터: Extended controls에서 디스플레이 배율 고정, 상태바 시계 의미 없으니 무시. 녹화 전 알림·토스트 정리.

대안(오디오 불필요 컷만): 에뮬레이터 단독은 `adb emu screenrecord start --time-limit 180 ~/Movies/emu.webm` / `adb emu screenrecord stop`.

### 2. 세로(숏폼) 만들기 — ffmpeg (설치됨)
가로 원본 `demo.mp4`(1920×1080, 왼쪽 1152px=앱, 오른쪽 768px=Console 가정)에서:
```bash
ffmpeg -i demo.mp4 -filter_complex "\
[0:v]crop=1152:1080:0:0,scale=1080:-2,pad=1080:810:0:(oh-ih)/2[app];\
[0:v]crop=768:500:1152:200,scale=1080:700[con];\
color=black:s=1080x410:d=1[cap];\
[app][con][cap]vstack=3,format=yuv420p[v]" \
-map "[v]" -map 0:a? -c:v libx264 -crf 20 -c:a aac short.mp4
```
- Console 크롭 좌표(`768:500:1152:200`)는 컷마다 보여줄 영역(Seat/Light/HVAC/Energy)에 맞춰 바꿈 → 컷별로 잘라 만든 뒤 이어 붙이거나, 편집툴(CapCut/iMovie)에서 위치만 키프레임.
- 배속 구간: `-filter:v "setpts=0.25*PTS"` (4배속, 오디오는 그 구간 제거).
- 자막·하이라이트 박스·엔드카드는 CapCut 또는 iMovie에서 추가 (설치된 ffmpeg의 libass 지원 여부가 확실하지 않아 편집툴로 처리).

### 3. 내레이션 생성
```bash
say -v Yuna -r 180 -o n01.aiff "전기차 급속 충전, 평균 사십칠 분."
```
`Yuna`가 없으면 시스템 설정 > 손쉬운 사용 > 읽기 및 말하기에서 한국어 음성 추가.
