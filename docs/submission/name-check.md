## 결론
**"충전쉼표 (Plug & Rest)" 유지 가능 (충돌 미발견).** 단, KIPRIS 결과는 JS 렌더링이라 자동 확인이 불완전 → 아래 수동 절차 1회(5분) 필요. 영문 표기는 `PlugRest` 단독 사용을 피하고 **"Plug & Rest"** + 한글 병기 권장(동명 개발자 라이브러리 존재).

## 수동 확인 절차 (사용자, 약 10분)
1. **KIPRIS**: kipris.or.kr → 상표 → 검색어 `충전쉼표`, `플러그앤레스트`, `PLUG REST` 각각 → 상품분류 **9류(소프트웨어)·42류(SaaS)** 필터 → 행정상태 "출원/등록/공고" 결과 확인. `쉼표`만 따로 검색해 9류 등록 상표가 있는지도 확인(결합상표 유사 판단용).
2. **Instagram**: 앱/웹에서 `@plugrest`, `@plugrest.app`, `@chungjeonswimpyo` 검색 → "사용자를 찾을 수 없음"이면 가용.
3. **.app 도메인**: 가비아·GoDaddy 검색창에 `plugrest.app` 입력.
4. 위에서 9류/42류에 동일·유사 등록이 나오면 아래 대안으로 교체.

## 권장 핸들/도메인
- 숏폼 계정: YouTube `@plugrest` / Instagram `@plugrest.app` (가용 시) — 실명 없는 앱 계정 요건 충족
- 도메인(필요 시): `plugrest.kr` 또는 `충전쉼표.kr` — 공모전 단계에선 구매 불필요(YAGNI)

## 대안 이름 2개 (충돌 확인 시)
1. **충전멍 (ChargeNap)** — '불멍·물멍' 밈 차용, 숏폼 훅과 궁합. 짧고 기억에 남음.
2. **쉼충 (RestCharge)** — "쉬면서 충전" 축약, 슬로건 "충전은 차가, 휴식은 당신이."와 의미 연결.
- 두 안 모두 동일 절차로 재확인 필요(이번 조사 범위 밖).
