## 2. 45초 대본 (선택안 A) — 에뮬레이터 화면 녹화만으로 촬영

### 촬영 셋업
- **데모 빌드 사용** (`BuildConfig.DEMO`: "계산 중" 20초, 충전 판정 10초) → 3분 대기 없이 녹화. 장면 6 화면 하단에 작은 자막 **"시간 단축 데모"** 상시 표기.
- Pleos 에뮬레이터 + Virtual Console을 나란히 띄운 화면을 녹화 (Android Studio 화면녹화 또는 macOS `Cmd+Shift+5`).
- 편집(CapCut 등)에서 9:16로 **상단 = 앱 화면 / 하단 = Virtual Console** 2단 분할. Console 조작(SOC 슬라이더, 시트·조명 값 변화)이 "실제 차 신호로 움직인다"는 증거 역할.
- 내레이션 = **앱 자체 TTS 음성 녹음** + 자막. 사람 목소리 불필요(신원 노출 0).
- 배경: 저작권 프리 로파이 1트랙, TTS 구간에서 덕킹.
- 화면 밝기/어두운 테마가 영상에서 묻히지 않도록 앱 영역 주변에 얇은 테두리·확대(줌 120%) 처리.

### 장면표

| # | 시간 | 화면 (녹화 소스) | 자막 (화면 텍스트) | 소리 / 내레이션 |
|---|---|---|---|---|
| 1 | 0:00–0:02 | 검은 화면 → 앱 Idle 화면, SOC 50% 크게 줌인 | **충전 47분, 아직도 폰만 보세요?** | 효과음 "띵" |
| 2 | 0:02–0:07 | Console: Gear=P, Charge Switch ON 클릭 → 앱 "휴식 모드 시작" 버튼 활성화 | 충전 꽂으면, 차가 먼저 알아챕니다 | 로파이 시작 |
| 3 | 0:07–0:11 | 앱에서 목표 칩 **80%** 탭 → "휴식 모드 시작" 탭 (터치 포인터 표시 ON) | 목표 80%. 원탭. | 탭 효과음 |
| 4 | 0:11–0:20 | 하단 Console 확대: 시트 등받이 각도 ↓, 통풍 ON, 앰비언트 밝기 ↓·웜톤, HVAC 22°C 값이 차례로 바뀌는 모습 (각 1.5초 컷) | 시트 젖히고 · 조명 낮추고 · 공조 22°C | 컷마다 "틱" |

| 6 | 0:25–0:32 | Console SOC 슬라이더를 10초 간격으로 5씩 50→79 (PRD 시연 스크립트와 동일). "계산 중…" 구간(데모 빌드 20초)은 점프컷 → 남은 시간 **"약 30분"** 표시 → 링 갱신 (배속) | 몇 분 뒤, 충전 속도로 남은 시간 계산 (하단: 시간 단축 데모) | 로파이 |
| 7 | 0:32–0:38 | SOC 80 도달 → 앱 Done 화면, Console에서 시트·조명·공조 원래 값 복귀 | 목표에 닿으면 깨워주고, 원래대로 | **TTS:** "목표 80%에 도달했습니다. 10초 후 시트를 원래대로 되돌립니다." (PRD v0.4 카운트다운 10초는 편집에서 점프컷) |

| 9 | 0:42–0:45 | 앱 아이콘 + 앱 이름 + 슬로건 (정적 엔드카드) | **충전은 차가, 휴식은 당신이.** Pleos Connect 앱 · 충전쉼표 (Plug & Rest) | 로파이 페이드아웃 |

- 총 45초. 1~3장면(11초) 안에 "문제→원탭"이 끝나야 이탈 방지.
- 4장면은 이 앱의 차량특화성 핵심(SDK 제어)이므로 Console 값 변화를 반드시 화면에 남길 것. PRD 리스크대로 에뮬레이터에서 Seat 반영이 안 되면 **조명·공조 컷만 사용**하고 자막을 "조명 낮추고 · 공조 22°C"로 축약.
- 주행 중 사용 장면은 넣지 않음(기어 P 고정). 안전 관련 오해 방지.

## 3. 앱마켓 등록용 소개문

### 한 줄 소개 (30자 이내)
- **"충전하는 동안, 차가 휴식 공간으로 바뀝니다"** (24자, 공백 포함)
- 예비: "충전 시작하면 원탭 휴식, 완료되면 음성 알림" (25자, 공백 포함)

### 상세 소개 (300자)

```
전기차 급속충전 평균 47분, 이제 차 안에서 제대로 쉬세요.
충전쉼표는 충전이 시작되면 원탭으로 차량을 휴식 공간으로 바꿉니다.
등받이를 젖히고 통풍·열선 시트를 켜며, 조명은 어둡고 따뜻하게, 공조는 쾌적하게 맞춥니다.
목표 배터리(80·90%)를 고르면 목표 도달을 감시하며 남은 시간을 계산해 보여주고, 목표에 도달하면 음성으로 알려준 뒤 시트·조명·공조를 원래대로 되돌립니다.
출발 전에는 열린 창문, 켜진 실내등, 뒷좌석 탑승자까지 한 번에 확인해 줍니다.
주행 중에는 조작이 잠겨 안전합니다.
```
(공백·줄바꿈 포함 약 290자 — 300자 이내)

### 키워드 10개
충전 대기, 전기차 충전, 휴식 모드, 차박, 릴렉스 시트, 앰비언트 조명, 충전 완료 알림, 배터리 SOC, EV, 낮잠

### 카테고리 제안: **Mobility Services** (권장) vs Lifestyle

| 기준 | Mobility Services | Lifestyle |
|---|---|---|
| 트리거 | 앱이 켜지는 이유가 **충전(에너지 상태)** — 모빌리티 행위 그 자체 | 휴식은 결과일 뿐 출발점이 아님 |
| 사용자 검색 의도 | "충전" 관련 앱을 찾는 EV 운전자가 바로 발견 | 음악·콘텐츠 앱과 섞여 발견성 저하 |
| 공모전 심사 정합성 | 차량특화성·기술활용성(EvBattery·Seat·HVAC·Light 제어) 메시지와 일치 | "휴식 앱"으로 읽히면 모바일 앱과 차별성이 약해 보임 |
| 경쟁 밀도 | 내비·충전 위주, "충전 대기 경험" 앱은 없음 → **카테고리 내 유일한 포지션** | 마켓 확대 예정 카테고리라 향후 혼잡 |
| 리스크 | 내비/충전소 앱으로 오인 → 한 줄 소개에 "휴식" 명시로 해소 | — |

결론: Mobility Services로 등록하고, 2차 카테고리(태그) 허용 시 Lifestyle 추가.

## 4. 심사위원 기억용 슬로건 5안

1. **충전은 차가, 휴식은 당신이.** ← **확정** (엔드카드·기획서 1번 한 줄 소개 후보)
2. 47분을 기다림에서 휴식으로.
3. 꽂으면 눕고, 차면 깨운다.
4. 충전소가 가장 편한 라운지가 되는 순간.
5. 배터리와 함께, 당신도 충전됩니다.
