## 1. 한 줄
EV 충전 대기 시간 동안 원탭으로 시트·조명·공조를 '휴식 공간'으로 바꾸고, 배터리(SOC) 기준으로 남은 시간을 알려주며, 충전이 끝나면 음성으로 깨우고 원래 상태로 되돌려 주는 Pleos Connect 앱.

## 2. 문제
- **[v0.5]** 급속 충전 1회 평균 47.2분은 서울 충전기 하루치 실측(한국ITS학회), "47분·희망 30분"은 컨슈머인사이트 설문(2021) — 근거 강도는 제안서에 명시. 유럽 급속 충전자의 **25%**가 차 안에 머무름(Gilbarco 2025). "절반"이라는 표현 금지.
- 현재는 수동으로 시트 젖히고, 조명 끄고, 공조 맞추고, 폰 타이머를 따로 맞춘다. 충전 완료를 놓치면 점유 수수료·뒷사람 대기.
- 현대·기아는 릴렉션 시트·유틸리티 모드·펫 모드 하드웨어가 있지만 "충전과 연동된 하나의 시나리오"가 없다 (research/04 §3). **[v0.3]** 기아 EV3/EV9·아이오닉 9 ccNC의 휴식 모드 유무는 검수 세션이 확인 후 문장 확정.
- **[v0.3] 전제**: 충전 중 인포테인먼트가 켜져 있고 공조·시트 제어가 허용되는 차종(유틸리티 모드 지원 차종)을 1차 대상으로 한다. 전원 상태 신호는 SDK에 없으므로 제어 실패(onFailed)는 "이 차량에서는 지원되지 않음"으로 표시하고 시나리오를 축소한다.
- **[v0.5] 차별점은 한 문장으로**: 기아 EV3는 이미 "충전 중 차 안에서 휴식"을 마케팅하고 릴렉션 시트·목표 SOC 자동 충전 중지는 순정이다. 이 앱의 차별점은 '젖히기'가 아니라 **'끝내기'의 자동화 — 목표 도달 알림 + 자동 복원 + 하차 점검**이다. "어디에도 없다"는 표현 금지(오너스 매뉴얼 미확인). 시연 1장면은 완료→깨움→복원에 집중.

## 3. 타깃 / 성공 지표
- 1차: Pleos Connect 탑재 EV 운전자 중 주 1회 이상 급속 충전하며 **차에 남아 기다리는** 사용자. **[v0.5]** 1차 모수는 아이오닉 3(2026 하반기). 기아 적용 시점은 **공식 발표 없음(추정)** — "2027"을 사실처럼 쓰지 말 것. 연 10만 대는 현대·기아 EV 전 차종 Pleos 적용 시의 가정.
- KPI **[v0.4]**: 충전 중 앱 실행 대비 휴식 모드 시작률(MVP에 자동 제안 없음) / 세션당 체류 분 / 완료 알림 후 60초 내 사용자 종료 비율(앱 내 측정 가능) / 세션당 추가 소비 kWh(EvBattery 효율 값으로 추정).

## 4. 사용자 플로우 (MVP)
1. **대기 화면**: 앱 실행 시 현재 SOC·충전 여부·기어 표시. 충전 중이면 "휴식 모드 시작" 큰 버튼 활성. **[v0.5 구현 확정] 충전 중 = 포트 == 연결 AND (최근 3분 SOC 상승 OR 충전 스위치 ON)**. 포트 capability 미지원 차량만 포트 조건 생략. 포트 null은 "모름"이지 충전 아님. 보조: `getEvChargeSwitchState` 10초 폴링은 Idle 화면에서만, 기어 `GEAR_PARK`. **[v0.5 구현 확정]** 한 번 충전 중으로 판정되면 SOC 상승이 없어도 90초 유지(깜빡임 방지), 포트 분리 시 즉시 해제. + 목표 SOC 칩(80 / 90%) **[v0.5]** 100% 삭제(급속기 점유 악화·테이퍼 구간 오차). 대기 화면에는 남은 시간을 표시하지 않음("시작 후 실제 충전 속도로 계산").
2. **휴식 모드 ON** (원탭):
   - 현재 시트/조명/공조 상태 스냅샷 저장 (**[v0.4]** 충전 한도는 건드리지 않으므로 제외)
   - **[v0.5] 리클라인 전 점검**: 뒷좌석(운전석 뒤) 착좌 감지되면 등받이 각도를 절반만 젖히고 안내. 리클라인 중 터치 시 즉시 정지.
   - 운전석 등받이 리클라인, 통풍 시트 선택(기본 OFF)
   - 앰비언트 라이트 어둡게·따뜻한 색, 실내등 OFF
   - HVAC 22°C, 풍량 1단, **외기 유입 기본**(재순환 장시간 CO2 상승 방지) **[v0.5]**. 통풍은 칩으로 선택(기본 OFF), 열선은 제어하지 않음 **[v0.5 구현 확정]**. **[v0.3]** SOC가 하한(기본 20%, 완속 충전 중 미적용) 아래면 공조 절전 + 안내
   - **[v0.4]** 목표 SOC는 앱 내부 값으로만 쓴다. `setEvChargePercentLimit`는 호출하지 않음(원래값 get API가 없어 복원 불가 → 사용자 설정 영구 변경 리스크 R5). 목표 도달은 SOC 리스너로 감시.
   - TTS **[v0.5]**: "휴식 모드를 시작합니다. 목표 80%에 도달하면 깨워 드릴게요." (시작 시 시간 언급 없음 — 처음 3분은 계산 중)
3. **휴식 화면**: 큰 SOC 링 + 남은 시간 + 목표. **[v0.3]** 남은 시간: 처음 3분은 "계산 중" 표시(TTS도 시간을 말하지 않음) → 이후 최근 5분 기울기 사용, 80% 초과 구간은 기울기×0.5 보정 [추정 계수, 실데이터로 교정], 표시는 5분 단위 반올림 + "약". **[v0.6]** 폴백 순서: 실측 기울기 → 학습값(§4.6, "지난 충전 기준") → 둘 다 없으면 "계산 중…" 유지. 고정 가정 기울기는 쓰지 않음(추측 금지). 화면 밝기 최소, 애니메이션 없음. "종료" 버튼 1개.
4. **종료 조건** (아무거나 먼저): SOC ≥ 목표 / 충전 중단 / 사용자 종료
   - **[v0.3] 주행 제한 진입(`CarUxRestrictionsManager.isRequiresDistractionOptimization()` 또는 기어 ≠ P)은 복원을 실행하지 않고 즉시 모든 제어를 중단한다.** 복원은 정차 상태에서만.
   - **[v0.5] 미복원 상태로 주행 후 다시 정차(기어 P·제한 해제)하면** 세션이 살아 있는 동안 1회 TTS "시트를 원래대로 되돌릴까요?" + 화면 "되돌리기/그대로" 제안. 브레이크 페달 감지 시 선제 복원은 유지(출발 전 복원 기회).
   - TTS 예고 **[v0.5]**: "목표 80%에 도달했습니다. 10초 후 시트를 원래대로 되돌립니다." (충전 한도를 바꾸지 않으므로 "충전 완료"라고 말하지 않음). 복원 후 Done 화면에서 확인 전이면 30초 간격 최대 3회 "목표 N%에 도달했습니다" 재안내 (구현 기준으로 확정). → 10초 카운트다운 + 화면 "취소" 버튼 → 복원. **[v0.4]** 취소 시: 복원하지 않고 세션 종료 → Done 화면("시트·조명·공조는 지금 상태 그대로예요") + 하차 체크. 되돌리기 보조 액션 없음(차량 기본 조작으로). **[v0.3]** 시트 이동 중 화면 터치 시 즉시 정지
   - 스냅샷 복원 (시트·조명·HVAC)
   - 브레이크 페달 감지(Brake register) 시 즉시 시트 선제 복원 (출발 의도)
   - **[v0.5 구현 확정]** Done에서 확인 미입력 시 재안내 3회 종료 또는 포트 분리 중 먼저 오는 시점에 Idle 복귀·서비스 종료. 단 **미복원 Done(restored=false)은 포트 분리로 리셋하지 않고** 되돌리기 제안 처리 또는 2시간까지 유지(검수 C1).
   - **하차 체크 카드**: 창문 열림, 실내등 ON, 뒷좌석 착좌 감지 → 한 줄 안내 ("뒷좌석에 사람이 있어요", 아동 표현 금지) **[v0.3]**
5. **주행 중 화면 없음 [v0.5]**: DO(Distraction Optimized)를 선언하지 않으므로 플랫폼이 주행 중 앱 사용을 막는다(Pleos 주행 규제 정책 명문). 앱은 별도 주행 화면을 만들지 않는다. 안전장치로 `isRequiresDistractionOptimization()` 또는 기어≠P 감지 시 모든 set 중단·복원 금지(§4.4)는 유지.

### 4.6 충전 속도 학습 **[v0.6 추가, 사용자 승인 2026-11-03]**
- 목적: 두 번째 충전부터 "이 차는 80%까지 보통 약 N분"을 바로 말해 줘 "계산 중" 공백을 메우고 차량 맞춤 경험을 보여준다(창의성 보강).
- 저장: 세션 종료 시 유효한 기울기(%/분, 최소 2분 데이터)를 **기기 로컬**에 지수이동평균(EMA, α=0.3)과 관측 횟수 n으로 저장. SOC 80% 이하 구간과 초과 구간을 따로 저장(테이퍼). VIN·계정 없음(이 차량 = 이 기기).
- 표시: n ≥ 1이면 Idle 보조 문구를 "지난 충전 n회 기준, 80%까지 보통 약 N분"으로, Resting "계산 중" 구간에는 "지난 충전 기준 약 N분"을 보조 표시 → 실측 기울기가 생기면 실측으로 전환(라벨 "실측"). 시작 TTS는 n ≥ 1일 때만 "지난 충전 기준 약 N분 예상입니다"를 덧붙임.
- 초기화: Idle 설정에서 "학습 기록 지우기" 1개. 처리방침 §3에 저장 항목 추가.
- Fake: 데모에서 2회째 세션부터 학습값이 보이도록 Fake 기울기 고정.

## 6. 아키텍처 (ponytail)
- 단일 Activity + Compose, 화면 3개 (Idle / Resting / Done) + **[v0.3] Foreground Service가 RestSession을 호스트** (리스너·TTS·복원은 서비스 소유, 알림 1줄 "휴식 모드 진행 중 · 목표 80%"). 백엔드·계정·DB 없음.
- `VehicleGateway` 인터페이스 1개, 구현 2개: `PleosVehicleGateway`(SDK 콜백 → StateFlow), `FakeVehicleGateway`(일반 AVD·단위테스트용, SOC가 시간에 따라 오름). 에뮬레이터 설치 전에도 개발·녹화 가능하게 하기 위한 유일한 추상화.
- `RestSession`: 상태머신 Idle→Resting→Done, 스냅샷 저장/복원, 남은시간 계산 (순수 Kotlin, 단위테스트 1개).
- 스냅샷은 메모리 + DataStore(프로세스 재생성 대비). **[v0.5 구현 확정]** 저장 후 2시간 경과 시 10초 예고 후 복원하고 세션 종료(폐기가 아님 — 젖혀진 시트를 남기지 않기 위해). 충전 포트 분리 시에도 동일.
- 샘플앱과 동일 스택: AGP 8.8.2 / Kotlin 2.0 / Compose BOM 2024.04 / compileSdk 35 / minSdk 28 / Vehicle 2.3.2.

## 7. Virtual Console 시연 스크립트 (2분)

3. SOC 슬라이더를 10초 간격으로 5씩 50→79 → 처음 3분 "계산 중" 후 링·남은시간 갱신 **[v0.3]**
4. SOC 80 → TTS 완료 안내, Console에서 시트·조명 복원 확인
5. Window 하나 열어둔 상태 → 하차 체크 카드에 "조수석 창문 열림" 표시
