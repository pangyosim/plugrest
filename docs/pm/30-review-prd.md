## 1. 심사 4축 예상 점수 (5점, 전부 추정)

| 축 | 점수 | 감점 사유 |
|---|---|---|
| 차량특화성 | 3.5 | 시트·조명·공조 제어는 차량 전용이 맞음. 그러나 "남은 시간 + 완료 알림"은 이미 제조사 충전 앱/폰 앱이 제공 → 앱 가치의 절반이 모바일 대체 가능. 실 사용 맥락(시동 OFF 충전 중 인포테인먼트 동작 여부)을 PRD가 증명하지 못함(리스크 1). |
| 창의성 | 2.5 | 아이오닉 5/6/9 릴렉션 시트는 이미 **버튼 하나로 무중력 자세** 진입(research/04 [15]). 테슬라 Camp/Keep Climate, 현대 유틸리티 모드 존재. 남는 차별점은 "SOC 연동 자동 복원" 하나 → 심사위원 첫 질문이 "기존 릴렉션 버튼 + 충전 알림 아닌가요?"일 가능성 높음. Pain point(충전 47분)는 명확하나 "왜 앱이어야 하나"가 약함. |
| 기술활용성 | 3.5 | Vehicle 4도메인 + TTS로 핵심 기능에 SDK가 쓰이는 점은 충족. 감점: 남은시간 계산식 단위 오류(§3-R8), Charge Switch를 "충전 중" 판정에 오용(R7), 기어 도메인 미확정 상태로 PRD 확정, STT/NaviHelper/FusedLocation 미사용(MVP), CarUxRestrictions 구현 방식 미기술. |
| 사업성 | 2 | Pleos Connect 첫 적용 차종은 그랜저·아반떼 = **비(非)EV**(research/04 §1). 국내 Pleos 탑재 EV 기반은 2026~27년 극소(아이오닉 3는 유럽 우선) → 타깃 모수가 사실상 0에서 시작. 수익 모델이 MVP에 0개(커머스·콘텐츠는 문장만). MAU·Retention 수치는 research/04에서 "가정"이라 명시한 값을 그대로 씀. KPI "자동 제안 수락률"은 MVP 플로우(사용자가 앱을 직접 실행)에 자동 제안이 없어 측정 불가. |
| **합** | **11.5 / 20** | 01-ideation의 24점은 과대평가. |

## 2. 탈락/반려 리스크 Top 10

| # | 리스크 | 영향 | 가능성 | 근거 |
|---|---|---|---|---|
| R1 | **시동 OFF·충전 중 인포테인먼트/전장 제어 가능 여부 미확인.** 실차에서 충전 중 차량이 OFF면 앱 자체가 안 돌거나 Seat/HVAC set이 거부될 수 있음. 에뮬레이터는 이 제약을 재현 못 함 | 치명(전제 붕괴) | 중 (추정) | Pleos 문서에 정책 없음. pm/02 A안도 동일 리스크 지적 |
| R2 | **Vehicle SDK 제어 권한은 App Market 사전 승인 필요.** CONTROL_CAR_SEATS/CLIMATE/LIGHTS/ENERGY 4종 모두 "별도 심사" 대상 | 높음(실출시), 중(공모전 PT 질문) | 높음 | R2 인용 |
| R3 | **기어 ≠ P 시 자동 복원 = 출발 순간 시트 등받이 이동.** PRD §4-4 종료 조건에 "기어 ≠ P"가 있고 그때 스냅샷 복원 → 운전자가 D 넣는 순간 시트가 움직임. 운행 안전 위해 요소로 즉시 반려 사유 | 치명 | 높음 | R1 "운행 안전에 위험 요소 … 거부" |
| R4 | **자동 시트 이동 시 끼임.** 리클라인 시 뒷좌석 탑승자/물건, 복원 시 잠든 사용자. PRD는 뒷좌석 occupancy를 "하차 체크"에만 쓰고 리클라인 전 검사 없음 | 높음 | 중 | 안전 일반 (추정) |
| R5 | **배터리 소모로 충전 지연 모순.** HVAC·통풍/열선·조명은 충전 전력 일부를 소비 → "휴식"이 충전 시간을 늘림. 급속(50kW+)에선 미미하나 완속(7kW)에선 공조 1~3kW가 충전 속도를 크게 깎음 (추정, 공조 소비전력 실측 출처 없음) | 중 | 높음(PT 질문 확률) | R5 "배터리 사용 최소화" |
| R6 | **`setEvChargePercentLimit` 부작용.** 사용자 차량의 전역 충전 한도를 덮어쓰고 스냅샷 복원 대상에 없음 → 다음 충전(집)에서 80%에서 멈춤. "사용자 설정을 몰래 바꾸는 앱"으로 반려 가능 | 높음 | 높음 | PRD §4-2, §4-4 스냅샷 항목에 누락 |
| R7 | **충전 판정 오류.** Charge Switch ON은 "충전 허용 스위치"일 뿐 "충전 중"이 아님(추정, 도메인 명세 재확인 필요). 포트 연결 + 충전 전류 > 0 이어야 함 | 중 | 중 | research/02 EvBattery 항목 |
| R8 | **남은 시간 계산식 오류.** "기본 50kW 가정"은 kW→%/분 변환에 배터리 용량(kWh)이 필요한데 식에 없음. 급속 충전은 80% 이후 급격히 느려져(테이퍼) 선형 외삽은 90/100% 목표에서 크게 과소추정. 100% 칩은 급속기 점유를 늘려 PRD가 내세운 "뒷사람 대기" 문제를 악화 | 중 | 높음 | PRD §4-3 |
| R9 | **테슬라/현대 기존 기능과 차별성 부족.** Camp Mode(공조 유지), 릴렉션 시트(원버튼 자세), 유틸리티 모드. "SOC 연동"만으로는 창의성 3 이하 | 높음(1차 탈락) | 중 | research/04 §3 |
| R10 | **사업성 모수 붕괴.** Pleos 첫 탑재 차종이 비EV. 타깃을 "Pleos 탑재 EV"로 한정하면 2027년까지 설치 기반 미미 → 사업성 최하점 | 높음(1차 탈락) | 높음 | research/04 §1 |

팩트체크(31-factcheck.md) 반영 — PRD에 직접 영향
- **PRD §2 "절반은 차 안에 머무름"은 근거 없음.** Gilbarco 2025: 유럽 급속 충전 중 차내 체류 **25%**. 타깃 모수 문장 전부 하향 필요(사업성 추가 감점 요인).
- **PRD §2 "급속 47분"은 2021년 설문(컨슈머인사이트), 47.2분 실측은 서울 하루치.** 근거 강도 약함 명시.
- **에뮬레이터 GPU 요구(최소 RTX 3060 Laptop급), Apple Silicon 언급 없음** → M4 Pro 구동 실패 시 2차 PT 시연 경로 자체가 막힘. §10 리스크 최상단에 추가.
- §5 조명 권한: 앰비언트 밝기·색·스위치 setter는 `CAR_LIGHTS`, 실내등 등 나머지는 `CONTROL_CAR_LIGHTS` → 표 수정.
- §6 Vehicle 2.3.2 선택은 맞음(2.3.1은 Nexus에 없음). 샘플 복사 시 버전 올릴 것.

차순위(Top 10 밖)
- **차속 신호 부재 전제 오류**: AAOS `PERF_VEHICLE_SPEED` 사용 가능(R6). 주행 판정은 CarUxRestrictions + 기어 + 차속으로 강화 가능. 반대로 "속도 없어서 못 한다"는 PRD/리서치 문장은 PT에서 지식 부족으로 보임.
- **개인정보·위치**: MVP는 위치·서버·계정 없음 → 개인정보 수집 0. 다만 R3는 처리방침 "공개"를 일반 의무로 적음 → 마켓 출시 시 1페이지 처리방침(수집 없음 명시) 필요. 공모전 단계에선 감점 요인 아님(추정). Phase 2 NaviHelper "주변 산책" 경로 저장 시 위치정보사업 신고 이슈(R3 7항).
- **상태 복원 의무**: R2. PRD §6 DataStore로 대응되어 있으나 "수 시간 이상 미사용 시 기본 상태" 예외 처리가 필요(충전 종료 후 다음날 재실행 시 Resting 복원은 오동작).
- **완료 알림 도달성**: 사용자가 잠들면 TTS 1회로 못 깸, 차 밖에 있으면 무의미(원격 알림은 비범위). "충전 완료를 놓치면 점유 수수료"라는 문제 정의를 MVP가 해결 못 함.
- **리크라인 상태 장시간 재순환 공조**: 수면 중 CO2 상승 (추정) → 외기 유입 기본값.

## 4. 이 아이디어를 버려야 할 조건

다음 중 하나라도 확인되면 Charge & Chill을 버리고 pm/02의 A안(뒷좌석 케어) 또는 범위를 줄인 하차 체크로 전환한다. ① Pleos 측 회신이나 문서로 **충전 중(시동 OFF) 상태에서 서드파티 앱의 Seat/HVAC 제어가 불가**하다고 확인될 때. 이때는 "휴식 공간으로 바꾼다"는 핵심 가치가 실차에서 성립하지 않는다. ② 1일차(11/4) Pleos 에뮬레이터에서 Seat move와 HVAC set이 **Virtual Console에 반영되지 않아** 2차 PT에서 "차가 바뀌는 장면"을 보여줄 수 없을 때. 이 경우 조명과 TTS만 남으므로 차량특화성·기술활용성 근거가 무너진다. ③ 리스크 R9 문장(“'끝내기'의 자동화”)으로 고쳐도 팀 내부 모의 심사에서 "릴렉션 버튼 + 충전 알림"이라는 반박을 넘지 못할 때. ④ 사업성 모수를 비EV 정차 휴식으로 넓히는 순간 테슬라 Camp Mode와 사실상 같은 제품이 되어 창의성 점수가 더 떨어질 때. 마감이 11/15이므로 **판정 기한은 11/5**로 둔다. 그 이후 전환하면 기획서와 APK를 둘 다 마감 전에 끝낼 수 없다 (추정).
